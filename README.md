# `NGO Website`

### Technology:

- Nuxt 3
- TypeScript
- Tailwind CSS
- Node `v18` or higher but LTS `v20.11` recommended

### MODE: SSR

## Production build

```bash
yarn
yarn install
yarn build
pm2 restart <id>
```

## Development Server

Start the development server on localhost:3000

```bash
yarn dev
```
